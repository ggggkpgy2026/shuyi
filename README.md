# 蜀一采购清单

一个纯前端的采购清单页面，可直接部署到 GitHub Pages。

## 功能

- 添加、编辑、删除采购商品
- 上传本地图片并预览
- 自动统计总金额、商品种类、总数量
- 导入/导出 JSON
- 导出 CSV
- Letter 横向彩色打印版

## 数据说明

数据保存在当前浏览器的 `localStorage` 中。部署到 GitHub Pages 后，添加、编辑、删除仍然可用，但数据只保存在当前设备和当前浏览器里。

建议定期使用“导出 JSON”备份，需要迁移到另一台电脑或浏览器时再用“导入 JSON”恢复。

## 部署

仓库根目录包含 `index.html`，可以直接用 GitHub Pages 从 `main` 分支根目录发布。
